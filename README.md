#  Expense_Tracker Application (Python)

##  Task Overview

This project is a simple command-line Expense Tracker built using Python.  
It allows users to manage and track their daily expenses efficiently using a menu-driven system.

---

##  Objective

To develop a basic interactive application that demonstrates Python fundamentals such as:
- Lists and dictionaries
- Loops and conditionals
- User input handling
- Menu-driven program design

---

##  Features

- Add new expense with category and amount
- View all recorded expenses
- Calculate total expenses
- Simple interactive CLI menu
- Runs continuously until user exits
- Safe exit option

---

##  Tools & Technologies

- Python 3
